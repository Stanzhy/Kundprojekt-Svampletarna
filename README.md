🍄 Svampletarna

Välkommen till repositoryt för Svampletarna – ett webbaserat kundprojekt utvecklat för föreningen Svampletarna. Webbsidan är skapad för att visa upp hittade svampar, utbilda om svampplockning och ge besökare möjlighet att spara sina egna fynd.

📋 Om Projektet

Föreningen önskade en lättanvänd och tillgänglig sajt med skogsinspirerade färger och en lugn, enfärgad bakgrund. Sidan är fullt responsiv och anpassad för både mobil och datorskärm.
